2. What “Test source” means

A successful test confirms that the selected source agent is online and responds to Dream Wi-Fi's tunnel control messages.

It does not prove that normal web browsing works yet. This webpage cannot change Android's network route or turn itself into a full-device VPN.

3. Use the connection on your device

  1. The receiving device needs a local proxy client connected to Dream Wi-Fi and configured to use the selected source.
  2. The current project includes a SOCKS5 proxy client for compatible environments, but it does not install itself from this page and it does not route all Android apps automatically.
  3. On Android, a full-device experience requires a dedicated app with Android's VPN permission, or another proxy-capable app configured for the local proxy. Do not install unknown APKs or share source credentials in chat.
  4. Keep both devices online while testing. Stop the source connector to end sharing.

The current website provides source discovery and a live tunnel-response test. It does not yet provide one-tap whole-phone internet sharing/receiving. We must verify real HTTP/HTTPS traffic through a source before calling the feature ready.
