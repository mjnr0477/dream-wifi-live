2. What this test proves

Test internet opens a TCP stream through the selected source and requests a page from example.com. A successful HTTP response confirms that the source has working outbound internet and that data returned through the tunnel. It does not prove that all apps on this receiving phone use the tunnel.

The native Android app uses Android VPNService, but its full-device routing and no-leak behavior have not passed physical-device acceptance tests. Android permission prompts cannot be bypassed. This web page alone cannot route all phone traffic.
