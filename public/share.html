Share your internet with Dream Wi-Fi.

If you're connected to Wi-Fi and want to volunteer your connection, this page explains the next step. Only share a connection you own or have permission to share.

Before you start

Important: Opening this link alone does not turn on internet sharing. A browser cannot start a background network relay on your phone. The source connector must be installed and authorized, and it must stay running while you share.
  1. Use a device connected to a Wi-Fi network with working internet.
  2. Install and run the Dream Wi-Fi source connector on that device. Android currently requires a compatible terminal environment; this is not a one-tap browser feature.
  3. Authorize the connector with a source credential provided through a secure setup process. Never post a source token publicly or send it in this link.
  4. Keep the device online. When the connector is connected, the source should appear as online in Dream Wi-Fi discovery.
  5. Stop the connector whenever you want to stop sharing. The relay is limited and is not a full-device VPN.

The current hosted service has the tunnel control plane, but a self-service pairing flow and a one-tap Android sharing app are not yet available. Do not assume your internet is being shared until the source appears online and a real connection test succeeds.

What the source shares

The current source connector relays supported HTTP/HTTPS traffic for a remote Dream Wi-Fi client. It does not give the remote person access to your private router admin page or local devices. Sharing may use your data plan, consume bandwidth, and be subject to the Wi-Fi provider's rules. Only enable it when you understand and accept those limits.

Dream Wi-Fi is separate from Dream Education. Public hotspot map listings do not themselves provide internet access.
